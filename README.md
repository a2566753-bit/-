# 🎯 أداة سنتر الليث

## وصف الأداة
أداة قوية لإضافة المنتجات إلى كتالوج فيسبوك تلقائياً. تقوم الأداة بتحويل بيانات المنتجات من ملف CSV وإضافتها إلى فيسبوك بيزنس بشكل تلقائي.

## المميزات
- ✅ تسجيل دخول آمن
- ✅ رفع ملفات CSV بسهولة
- ✅ إضافة المنتجات تلقائياً إلى فيسبوك
- ✅ تحويل روابط الصور إلى صور حقيقية
- ✅ واجهة عربية سهلة الاستخدام
- ✅ إدارة المنتجات (حذف، تعديل)

## متطلبات التشغيل
- Node.js v14+
- npm
- حساب فيسبوك

## الخطوات الأولى

### 1. التثبيت
```bash
npm install
```

### 2. إنشاء ملف .env
```
PORT=3000
SESSION_SECRET=your-secret-key
```

### 3. تشغيل الأداة
```bash
npm start
```

### 4. فتح الأداة
افتح المتصفح واذهب إلى: `http://localhost:3000`

## طريقة الاستخدام

### الخطوة 1: التسجيل أو تسجيل الدخول
- اختر بين إنشاء حساب جديد أو تسجيل الدخول
- أدخل بريدك الإلكتروني وكلمة المرور

### الخطوة 2: رفع ملف المنتجات
- اختر ملف CSV يحتوي على:
  - name (الاسم)
  - price (السعر)
  - description (الوصف)
  - imageUrl (رابط الصورة)

### الخطوة 3: ربط حساب فيسبوك
- أدخل بريد فيسبوك الخاص بك
- أدخل كلمة المرور
- اضغط على زر "ربط فيسبوك"

### الخطوة 4: بدء إضافة المنتجات
- اضغط على زر "بدء إضافة المنتجات"
- ستقوم الأداة بإضافة جميع المنتجات تلقائياً

## صيغة ملف CSV

```csv
name,price,description,imageUrl
منتج 1,100,وصف المنتج الأول,https://example.com/image1.jpg
منتج 2,200,وصف المنتج الثاني,https://example.com/image2.jpg
```

## التكنولوجيات المستخدمة
- Express.js - الخادم
- Puppeteer - أتمتة المتصفح
- CSV Parser - قراءة ملفات CSV
- Bcrypt - تشفير كلمات المرور
