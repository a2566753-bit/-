# 🚀 أداة إضافة المنتجات للفيسبوك - تلقائياً

أداة احترافية لإضافة آلاف المنتجات تلقائياً لكتالوج فيسبوك Business AI.

## المميزات

✅ **تحميل CSV** - دعم ملفات تصل لآلاف المنتجات
✅ **إضافة تلقائية** - تضيف المنتجات واحد تلو الآخر
✅ **تحميل الصور** - من imgur مباشرة
✅ **تتبع التقدم** - عرض نسبة الإكمال
✅ **سهلة الاستخدام** - واجهة عربية سهلة
✅ **آمنة** - تسجيل دخول آمن للفيسبوك
✅ **سريعة** - معالجة سريعة للبيانات

## متطلبات النظام

- Node.js v14+
- npm
- المتصفح الأحدث
- اتصال إنترنت سريع

## التثبيت والتشغيل

### 1. التثبيت
```bash
cd facebook-automator
npm install
```

### 2. إنشاء ملف .env (اختياري)
```
PORT=3000
NODE_ENV=development
```

### 3. التشغيل
```bash
npm start
```

### 4. فتح التطبيق
```
http://localhost:3000
```

## صيغة ملف CSV

يجب أن يحتوي الملف على الأعمدة التالية:

```csv
ID,Name,Price,Stock,Description,Image
1,منتج 1,100,50,وصف المنتج,https://imgur.com/image.jpg
2,منتج 2,200,30,وصف المنتج 2,https://imgur.com/image2.jpg
```

## خطوات الاستخدام

### الخطوة 1: تحميل الملف
1. اضغط على منطقة تحميل الملف
2. اختر ملف CSV
3. اضغط "تحميل الملف"

### الخطوة 2: تسجيل الدخول
1. اضغط "تسجيل الدخول للفيسبوك"
2. سجل دخولك في النافذة الجديدة
3. وافق على الأذونات

### الخطوة 3: بدء الإضافة
1. اضغط "بدء إضافة المنتجات"
2. اترك النافذة مفتوحة حتى تكتمل العملية
3. تابع التقدم في الشاشة

## الأعمدة المدعومة

| العمود | النوع | الإلزامي | الوصف |
|--------|-------|---------|-------|
| ID | نص | ✓ | معرف فريد للمنتج |
| Name | نص | ✓ | اسم المنتج |
| Price | رقم | ✓ | سعر المنتج |
| Stock | رقم | ✓ | الكمية المتاحة |
| Description | نص | ✓ | وصف تفصيلي |
| Image | رابط | ✓ | رابط الصورة (imgur) |

## نصائح مهمة

1. **تنسيق CSV**: تأكد من أن الملف بصيغة UTF-8
2. **الصور**: استخدم روابط imgur أو صور عامة
3. **الأسماء**: تجنب الأحرف الخاصة في الأسماء
4. **الوصف**: كن واضحاً وشاملاً في الوصف
5. **عدم الإغلاق**: لا تغلق المتصفح أثناء الإضافة

## معالجة الأخطاء

### مشكلة: "خطأ في تحميل الملف"
- تأكد أن الملف بصيغة CSV
- تأكد من وجود جميع الأعمدة المطلوبة
- تأكد من ترميز UTF-8

### مشكلة: "فشل تسجيل الدخول"
- امسح ملفات تعريف الارتباط
- استخدم متصفح حديث
- تأكد من اتصال الإنترنت

### مشكلة: "توقفت الإضافة"
- تحقق من اتصال الإنترنت
- أعد تشغيل الخادم
- جرب ملف أصغر للاختبار

## البنية التكنولوجية

**Backend:**
- Express.js - الخادم
- Puppeteer - التحكم بالمتصفح
- Multer - رفع الملفات
- CSV Parser - قراءة ملفات CSV
- Axios - طلبات HTTP

**Frontend:**
- HTML5 - الهيكل
- CSS3 - الأسلوب
- Vanilla JS - التفاعل

## الأداء

- **سرعة الإضافة:** 10-20 ثانية لكل منتج
- **عدد المنتجات:** تدعم حتى 10,000 منتج
- **الوقت الإجمالي:** ~166 دقيقة لـ 1000 منتج
